# 🎨 Фотошоп 2.0 (Photoshop 2.0) — Android Photo Editor

Сучасний мобільний фоторедактор для Android, розроблений у рамках практичного заняття та домашнього завдання. Додаток підтримує роботу як на фізичних пристроях з камерою, так і на емуляторах Android (із вебкамерою або фотографіями, завантаженими з інтернету/галереї).

## 🚀 Основний функціонал

### 1. 📷 Джерела зображень
- **Камера / Вебкамера**: створення знімка наживо (на фізичному смартфоні або через вебкамеру емулятора) за допомогою `FileProvider` та сучасного API `ActivityResultContracts.TakePicture`.
- **Галерея / Завантажені з інтернету**: відкриття будь-яких файлів картинок через системний Photo Picker (`ActivityResultContracts.GetContent`).
- **Підтримка Intent-ів (Open with...)**: можливість відкривати фотографії прямо з браузера або файлового менеджера через меню "Відкрити за допомогою Фотошоп 2.0".

### 2. 🎨 14 художніх фільтрів
1. **Оригінал** — початкове зображення.
2. **Ч/Б** — класичний монохром із вивіреною шкалою сірого.
3. **Сепія** — теплий ретро-ефект фотографій початку XX століття.
4. **Кіно** — кінематографічний градієнт у стилі Hollywood Teal & Orange.
5. **Теплий** — ефект "золотої години" (Golden Hour sunset).
6. **Холодний** — нордичні прохолодні блакитні тони.
7. **Яскравий** — підсилена насиченість та динамічний діапазон (Vivid / Pop).
8. **Вінтаж** — плівкова естетика 70-х років.
9. **Нуар** — глибокий висококонтрастний драматичний чорно-білий стиль.
10. **Неон (Кіберпанк)** — фіолетово-бірюзові неонові відтінки майбутнього.
11. **Драматичний** — глибокі тіні та підсилені контури.
12. **Віньєтка** — м'яке радіальне затемнення по краях кадру.
13. **Розмиття** — м'який фокус (Soft focus / dream blur).
14. **Негатив** — інверсія кольорів (ефект рентгенівської плівки).

### 3. ✂️ Інтерактивна обрізка (Crop Tool)
- Власний інтерактивний видошукач `CropOverlayView` із затемненням фону, рамкою та сіткою правила третин (Rule of Thirds).
- Зручні маркери на кутах для точного масштабування та перетягування області обрізки.
- Пресети пропорцій в один дотик:
  - **Вільна обрізка** (Free form)
  - **1:1 Квадрат** (ідеально для Instagram / аватарів)
  - **4:3 Фото** (класичний формат знімків)
  - **16:9 Відео** (широкий формат для YouTube та моніторів)
  - **9:16 Stories** (вертикальний формат для TikTok / Instagram Stories / Reels)
  - **3:4 Портрет**

### 4. 🔄 Трансформація фото (Rotate & Flip)
- **Поворот на 90°** праворуч (за годинниковою стрілкою).
- **Поворот на -90°** ліворуч (проти годинникової стрілки).
- **Віддзеркалення по горизонталі (Flip Horizontal)** — незамінно для дзеркальних селфі та вебкамери.
- **Віддзеркалення по вертикалі (Flip Vertical)**.

### 5. 🎛️ Тонка ручна корекція (Adjustments)
- **Яскравість (Brightness)** від -80 до +80.
- **Контрастність (Contrast)** від 0.5x до 2.0x.
- **Насиченість (Saturation)** від 0.0x (монохром) до 2.0x (гіпернасичений колір).
- Підтримка живого попереднього перегляду під час перетягування слайдерів.
- Кнопка швидкого скидання повзунків та кнопка збереження змін.

### 6. ↩️ Система Undo / Redo
- Повноцінна історія дій: кнопки "Назад" та "Вперед" у верхній панелі дозволяють без зусиль скасувати або повторити будь-яку операцію редагування.
- Кнопка "Скинути" повертає фото до початкового стану без втрати якості.

### 7. 💾 Збереження та Поділитися
- **Збереження в галерею**: експорт у каталог `Pictures/Photoshop2.0` через сучасний `MediaStore API` без втрати якості (JPEG 95%).
- **Поділитися (Share)**: відправка готового зображення у будь-який месенджер (Telegram, Viber, WhatsApp) або соцмережу в один клік через системний шеринг.

## 🛠️ Стек технологій
- **Мова**: Java 11
- **Платформа**: Android SDK (Min SDK: 33, Target SDK: 36)
- **UI Framework**: Google Material Design 3 (Material3 Dark Theme, Cards, Sliders, Toggle Groups)
- **Обробка зображень**: Android Native Graphics (`Canvas`, `Paint`, `ColorMatrix`, `Matrix`, `RadialGradient`, `ExifInterface`)
- **Асинхронність**: `ExecutorService` (фонова обробка фільтрів без блокування UI потоку)
- **Тести**: JUnit 4 (Unit-тести на безпеку та фільтри)
